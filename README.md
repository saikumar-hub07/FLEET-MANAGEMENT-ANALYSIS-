# FLEET-MANAGEMENT-ANALYSIS-
Fleet Management Analysis – Machine Learning Mini Project
A single-page project that applies machine learning to fleet management. It predicts which vehicles are likely to need maintenance within the next 30 days and groups the fleet into segments. Everything runs in the browser with plain HTML, CSS and JavaScript, so there is nothing to install.
Problem statement
Fleet operators lose money when vehicles break down unexpectedly. If we can predict which vehicles are most at risk, maintenance can be scheduled before a failure happens, which reduces downtime and repair cost.

Dataset
The data is synthetic and generated by a seeded random generator, so results are repeatable. Each vehicle has these features:
Age (years)
Odometer (km)
Daily distance (km)
Fuel efficiency (km/l)
Days since last service
Harsh brakes per 100 km
The target label y is 1 if the vehicle needed maintenance within 30 days, otherwise 0.
To use real data, replace the generateData() function in the HTML file with a CSV loader that returns objects with the same field names (age, odo, daily, fuel, days, harsh, y).
Method
Generate data for the chosen number of vehicles.
Split into 80% training and 20% test data.
Standardize features using the training mean and standard deviation.
Train logistic regression for 500 epochs, learning rate 0.1, small L2 penalty.
Evaluate on the test set using accuracy, recall and a confusion matrix.
Cluster all vehicles with k-means and label the segments by average age.
Rank vehicles by predicted risk and show the top 10.
How to run
Put fleet_analysis.html anywhere on your computer.
Double-click it to open it in a browser (Chrome, Edge, Firefox or Safari).
Change the number of vehicles or the random seed, then click Generate data and train.
No internet connection or server is required.

Limitations
The dataset is synthetic, so the accuracy shown reflects the rules used to create the data, not real-world performance. Always validate on real fleet records before using the predictions for decisions.
